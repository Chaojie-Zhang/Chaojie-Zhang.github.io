理解 Transformer（1）

Created on September 18, 2026

2026   ·   Machine Learning   Transformer   Learning Notes

本文介绍 Transformer 从输入文本到输出预测的基本计算过程，包括 token embedding、QKV、多头注意力、残差连接、encoder–decoder，以及训练和推理的区别。阅读需要矩阵乘法和梯度的基础知识。

文中以《Attention Is All You Need》的原始架构为主，并在相关位置说明它与 GPT-2 的区别。例句的分词、注意力权重和小矩阵均为教学示例，不是实际模型的测量结果。

1. 词表大小、序列长度与隐藏维度

计算中需要区分三个量：

符号 含义 决定什么
\(N_{\mathrm{vocab}}\) 词表里有多少种 token embedding 表有多少行
\(S\) 这次输入有多少个 token 当前状态矩阵有多少行
\(d\) 每个位置有多少个内部通道 当前状态矩阵有多少列

“100k 上下文”说的是可容纳的 token 数量上限。实际输入只有 1,000 个 token 时，当前序列长度就是 1,000。词表里的其他 token 不会因此各占一个注意力位置。

分词器有不同设计。BPE 等子词方法会从较小单位出发，把频繁出现的组合合并为 token。词表不必收录每一个完整单词：一个没见过的长词，仍可能被拆成已有片段。采用完整字节覆盖的方法可以进一步用字节表示输入；其他方法可能需要未知 token。

词表大小通常通过实验和预算取舍。词表小，文字可能切得更碎；词表大，embedding 和词表输出层更大，一些罕见 token 也更难获得充分训练。在模型训练完成后，词表和编号映射通常保持固定。

2. Token embedding

每个 token 有一个编号。编号用于查表，其大小和相邻关系不表示语义关系。Embedding 表的尺寸是：

\[E\in\mathbb{R}^{N_{\mathrm{vocab}}\times d}.\]

从表中取出当前输入的 \(S\) 个 token 对应的行，按顺序排列：

\[X_{\mathrm{token}}\in\mathbb{R}^{S\times d}.\]

每个位置由一个向量表示。向量的数值通过训练确定，单个分量通常没有明确的语义标签，信息可以由多个分量共同表示。

从头训练时，embedding 权重通常随机初始化，然后与整个网络一起优化。训练好的模型直接加载这张表。同一个 token 的初始向量相同，但后续会根据上下文产生不同状态。

这里要一直区分两类量：参数是模型保存的可训练数值；状态是给定输入后计算出的中间结果。 初始 embedding 是参数表的一行；某一层里这个位置的状态，则是输入相关的计算结果。

3. 位置编码

原论文给 token embedding 加上位置编码。两者列数相同，都是 \(d\)。它并不是把整个词表和整个位置表相加，而是先分别取出当前序列需要的 \(S\) 行：

\[X=\sqrt{d}\,X_{\mathrm{token}}+P,\qquad X,P\in\mathbb{R}^{S\times d}.\]

token 编号决定从 embedding 表取哪一行；位置编号决定使用哪个位置向量。词表有多少行，与可表示多少个位置没有必要相等。

同一个 token 出现在不同位置时，token embedding 相同，位置编码不同。相加后，网络便能利用位置差异区分不同的排列顺序。

原始 Transformer 使用固定的正弦、余弦位置编码，不同通道具有不同频率。后来的 GPT-2 使用可学习的绝对位置表。前者的位置向量由公式生成，后者的位置向量参与训练，不能混为一谈。[1, 2]

4. Q、K、V：三个投影，三个角色

对于一个注意力头：

\[Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.\]

若隐藏维度为 512、每个头宽度为 64，那么三个参数矩阵都是 \(512\times64\)，Q、K、V 都是 \(S\times64\)。

量 直观角色
Q（query） 接收位置用什么特征寻找信息
K（key） 源位置用什么特征与查询匹配
V（value） 源位置实际提供什么内容

“bank 的 query”只是 Q 矩阵中 bank 所在位置的那一行。它不是另外一套模型参数。同一个头中，所有位置都使用相同的 \(W_Q\)；矩阵乘法只是一次完成了每一行的投影。

K 用于计算匹配分数，V 用于后续的加权求和。分别使用两个可训练投影，使模型可以独立调整匹配所需的特征和需要传递的内容。

5. 注意力权重与加权求和

先计算：

\[QK^\mathsf{T}:\quad (S\times64)(64\times S)=S\times S.\]

每一行是一个接收位置，每一列是一个源位置。Q 的某一行与 K 的每一行分别做点积，得到 \(S\) 个分数。点积内部对通道求和，但不同源位置的分数分别保留。

然后得到注意力权重：

\[A=\operatorname{softmax}_{\mathrm{row}} \left(\frac{QK^\mathsf{T}}{\sqrt{64}}+\mathrm{mask}\right).\]

softmax 按行执行，每行非负、总和为 1。缩放用于控制点积分数的尺度。需要因果遮挡时，把不允许读取的位置设为负无穷，使其权重为零。

最后才是内容的混合：

\[H=AV:\quad(S\times S)(S\times64)=S\times64.\]

假设输入是 river｜near｜bank，bank 那一行的权重为 \([0.7,0.1,0.2]\)，三个 value 分别是 \([10,0]\)、\([0,5]\)、\([2,3]\)，那么：

\[H_{\mathrm{bank}}=0.7[10,0]+0.1[0,5]+0.2[2,3]=[7.4,1.1].\]

第一步里，其他位置的 K 影响 bank 的读取权重；第二步里，其他位置的 V 被混合进 bank 的输出。即使 bank 的初始向量不变，把 river 换成 money，周围的 K、V 变了，输出也可以变化。

这解决了一个看似矛盾的问题：bank 在 embedding 表中只有一行，为什么可以适应不同语境？因为共享的初始表示经过了不同上下文的处理。本次计算得到的新状态不会直接写回 embedding 表；训练时更新表的是反向传播得到的梯度。

将输入依赖关系显式写出：

\[H=A(X)V(X).\]

给定 A 后，加权求和对 V 是线性的；整体注意力操作则是非线性的，因为 A 也由输入计算得到。注意力权重描述这一层的信息读取，不能单独解释模型的最终判断。

6. 多头注意力

每个头都读取完整的输入向量，再形成自己的低维 Q、K、V。把数字缩小，假设输入为 \([1,2,3,4]\)：一个头可以输出 \([1+3,2+4]=[4,6]\)，另一个头可以输出 \([1+2+3+4,1-2+3-4]=[10,-2]\)。两者都使用了完整输入，只是投影权重不同。

真实模型中，一个 64 维输出通道也可以混合全部 512 个输入分量。多个头的投影可以并排放成大矩阵，一次乘法算完，再拆成各头。这是等价的执行方式。

需要分别计算的是各头自己的注意力矩阵 A。 这样同一个接收位置可以同时用几套不同的权重读取不同内容。若直接把所有通道合起来只做一次 softmax，就只剩一套共享的位置权重。

8 个头的输出拼接为 \(S\times512\)，再乘 \(W_O\in\mathbb{R}^{512\times512}\)。这里允许不同头的信息相互混合。没有一个裁判挑出“最正确的头”，各头也不一定在回答同一个问题。它们在共同损失下协作，也可能冗余。

同一层各头的注意力计算不等待其他头的结果；下一层则可以基于上一层已经整合的信息继续处理。头数增加并行读取方式，深度增加有先后依赖的处理轮次。 若隐藏维度固定，更多头通常意味着每头更窄，并不自动带来更强能力。

7. 残差连接与 MLP

注意力输出 O 与输入 X 尺寸相同。残差把它作为更新加回去：

\[Z=\operatorname{LayerNorm}(X+O).\]

为什么是 \(X+O\)，而不是 \(0.1X+O\)？系数 1 让模块在 \(O\approx0\) 时容易保持原状态。反复乘 0.1 会衰减，反复乘 10 会放大；网络虽可学习补偿，但单位系数提供了简单的恒等通路。其他残差缩放方案当然也存在。

看一个标量例子就能理解梯度路径：

\[z=x+f(x),\qquad \frac{dz}{dx}=1+f'(x).\]

那个 1 让梯度除了经过处理模块，还可以直接回到更早的状态。它有助于训练深层网络，但不保证梯度永远稳定；原论文的 LayerNorm 等操作仍会影响完整梯度。

接下来，MLP 对每一行使用同一套参数：

\[F=\operatorname{ReLU}(ZW_1+b_1)W_2+b_2.\]
参数或结果 尺寸
\(W_1\) \(512\times2048\)
\(b_1\) \(2048\)，广播到每一行
中间结果 \(S\times2048\)
\(W_2\) \(2048\times512\)
\(b_2\) \(512\)，广播到每一行
F \(S\times512\)

偏置的大小不随输入长度变化。ReLU 提供非线性，否则两个矩阵乘法可以合成一个。MLP 在每个位置内部加工已经收集到的信息，本身不跨位置通信。然后再做一次残差与归一化：

\[X_{\mathrm{new}}=\operatorname{LayerNorm}(Z+F).\]

这就是原论文 encoder block 的主干。原论文在残差相加前等位置还使用 dropout；为简化表达，这里没有把它写进每条公式。

8. 原始 Transformer：两条序列，三种注意力

下面按原论文 Figure 1 重绘，数据从上向下流动。[1] 为避免把例子的数字混在一起，本文主线采用原论文 base 配置：隐藏维度 512，8 个头，encoder 和 decoder 各 6 层。此前常见的 GPT-2 small 示例则是 768 维、12 个头和 12 个 decoder-only block；它的 MLP 激活、位置表示和归一化顺序也不同。[2]

原文经过六层 encoder，得到 C，尺寸仍为“原文长度 × 512”。它没有被压成单个句子向量。Encoder 的自注意力能读取原文的前后位置（不读取补齐用的 padding）。

Decoder 先对译文前缀做因果自注意力，随后通过交叉注意力读取 C。三种注意力的区别是来源与遮挡方式：

模块 Q 的输入来源 K、V 的输入来源 可读取范围
Encoder 自注意力 当前原文状态 当前原文状态 完整原文
Decoder 自注意力 当前译文状态 当前译文状态 自己及之前的译文位置
Decoder 交叉注意力 decoder 自注意力子层处理后的状态 encoder 最终输出 C 完整原文

假设 decoder 当前有 3 个位置，原文有 5 个位置。一个交叉注意力头中，Q 为 \(3\times64\)，K、V 为 \(5\times64\)，所以：

\[QK^\mathsf{T}:3\times5,\qquad AV:3\times64.\]

输出仍对应 decoder 的三个位置，却已经读取了原文。残差加回的是 decoder 状态，不是 C。每个 decoder block 都读取同一个最终 C，但使用各自的投影参数；不是第几层 decoder 对接第几层 encoder。

9. 没有 encoder，为什么也能翻译？

GPT-2 这类 decoder-only 模型，把任务提示、原文和译文前缀放进同一条序列：

英文：The beam gained energy. 中文：电子束……

生成中文时，英文已经在前面，因果自注意力可以读取它。Self-attention 的 self 指同一组序列表示，不是一个 token 只能读取自己。 跨 token 读取仍是 self-attention；Q 来自 decoder、K 和 V 来自另一个 encoder 的表示序列，才是这里的 cross-attention。

因此，decoder-only 不需要为了接收文字输入而额外增加交叉注意力。能否做好翻译还取决于训练数据与训练方式，架构提供可行的信息通道，并不自动赋予能力。

10. 推理：为什么只用最后一行？

Decoder 最终状态经过词表投影和 softmax，每个位置产生一个“下一个 token”的分布。若当前输入是：

<开始>｜电子束｜获得

第一行预测“开始”后面是什么，第二行预测“电子束”后面是什么，第三行预测“获得”后面是什么。现在需要的是新 token，所以读取最后一行。前面的位置依然重要：它们提供了最后一行需要读取的信息。

选出新 token 后加入前缀，继续预测，直到结束标记或长度限制。最直接的实现每次重算完整前缀；实际推理通常缓存各层已有位置的 K、V。因果遮挡保证旧位置不依赖后来追加的 token，因此其缓存可以复用。原文固定时，encoder 输出也可复用。

“选择 token”不一定等于每次取最大概率。可以贪心、采样或做束搜索；原论文的翻译实验采用束搜索。这里只追踪一条候选序列，以看清计算流程。

11. 训练：给出正确前缀，预测紧跟其后的 token

理想化地，准备一对原文和正确译文。中文切分仍只是示意：

Decoder 输入 监督目标
<开始> 电子束
电子束 获得
获得 了
了 能量
能量 <结束>

这就是右移一位的输入。训练时 decoder 使用正确前缀，即使自己在前一个位置预测错了，也不在这次计算中用错误预测替换输入。这叫 teacher forcing。

因果遮挡让每个位置不能偷看后面的答案。因此，所有位置可以在一次前向计算中同时训练。得到“目标长度 × 词表大小”的概率矩阵后，不必先抽样生成词，直接计算正确 token 的概率损失：

\[L_{\mathrm{position}}=-\ln p(\text{正确 token}).\]

概率为 0.1、0.5、0.9 时，损失分别约为 2.30、0.69、0.11。正确答案的概率增加，即使它暂时还不是排名第一的候选，目标函数也能体现进步。这里展示普通交叉熵；原论文还加入 label smoothing。

把有效目标位置的损失汇总，通过链式法则反向传播，再更新参数。用最简单的梯度下降表示：

\[w_{\mathrm{new}}=w_{\mathrm{old}}-\eta\frac{\partial L}{\partial w}.\]

一次前向、反向计算期间参数不变，算完梯度后才更新。Embedding、注意力投影、MLP、归一化中的可训练参数和输出层都可参与；Q、K、V 是中间结果，不作为独立参数更新。

训练优化的是所有样本上的共同目标。Encoder 不需要单独的目标表示 C：最终预测损失的梯度会通过交叉注意力传回 encoder。各个注意力头也不需要预先指定任务。

不同样本的梯度可能相反，参数确实会被来回调整。Batch 平均能减小单条样本带来的波动，并适合硬件并行；学习率决定每步走多远。两者是不同的控制量，不存在“越小越好”的普遍规则。原论文实际使用 Adam，而不是这里为解释方便采用的普通梯度下降。

训练时正确前缀已知，能并行计算多个位置；生成时未来 token 未知，需要逐个推进。这种差别也带来风险：推理时一次错误会改变后续前缀。因此，除了验证损失，还需要让模型真正生成完整译文来检查效果。

12. 模型容量与训练数据

参数多意味着可用容量更大，不保证已经学到了更多。数据不足时，大模型可能记住训练样本而泛化不佳；模型过小，也可能无法表达所需规律。模型大小、数据量和计算量要一起考虑，不能只数参数。本文停留在概念层面，不把某个经验比例当作普遍定律。

本文介绍基本计算过程。KV cache 的实现、长序列的计算成本、分布式训练和数值精度等工程问题，留待后续讨论。
